# Concept A reference for Nails For You

Start with [`a.html`](a.html). Its scroll animation also uses [`shared.css`](shared.css) and [`shared.js`](shared.js). This branch preserves the original Concept A opening study as a visual and interaction reference for a separate Nails For You redesign.

The study was originally made for Beautique Bar. Its brand name, copy, photographs, salon list, and booking links are temporary reference content. Do not treat them as approved Nails For You content. The Nails For You redesign should use the correct brand, location details, images, and booking destination after verification.

The distinctive idea to explore is the editorial opening: a framed manicure image expands while scrolling, then gives way to a second image and copy panel. Keep the deliberate typography, restraint, and reversible scroll behaviour while adapting the full site to Nails For You. This is only an opening study, not a finished website.

This branch is separate from `main` and the Concept B branch. Do not change the live website, production DNS, Ads, analytics, or booking systems while exploring the redesign.

To view locally, serve the repository root with a static HTTP server and open `/a.html`. The study loads two images from the existing Beautique Bar site and fonts from Google Fonts, so those parts need an internet connection.
